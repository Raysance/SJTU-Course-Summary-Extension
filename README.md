# SJTU 课程资料助手

用于从已登录的 SJTU Canvas 读取新版课堂实录并导出课程概要，可用 DeepSeek、ChatGPT、Claude 或 Gemini 生成按日期整理的课堂笔记；也支持读取课程“文件”页面，勾选课件后一键打包下载 ZIP，以及在本地监测直播画面中的二维码并提醒。

## 安装

1. 下载并解压本项目。
2. 打开 Chrome，进入 `chrome://extensions`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择项目中的 `chrome-extension` 文件夹。

需要 Chrome 116 或更高版本。

更新版本时，在 `chrome://extensions` 里点击该扩展的“重新加载”，然后刷新课程视频页。

## 使用方法

1. 在 Chrome 中登录 `https://oc.sjtu.edu.cn/`。
2. 点击 Chrome 工具栏中的“SJTU 课程资料助手”扩展图标。
3. 在扩展页面点击“重新读取”，扩展会通过 Canvas API 获取本学期课程列表；识别到多个课程时，可在顶部选择目标课程。也可以先打开课程的 `文件` 页面，再点击扩展图标，扩展会优先定位到该课程。

视频功能使用新版 `jy-application-resourcemanage-ui` 播放中心。插件会从每门课的实际导航中识别入口，无需选择版本或填写工具编号。已停止维护的旧版入口不再用于读取视频；课程文件下载不受视频入口是否开放的影响。

## 课程文件打包下载

选择课程后，“课程文件”模块会自动读取该课程文件。可搜索文件名或文件夹路径，勾选需要的文件后点击打包下载按钮，扩展会生成一个 ZIP 文件并保留课程文件夹路径。ZIP 文件名会使用当前选择的课程名。遇到 Canvas API 不可用时会回退到当前课程文件页的实际 DOM 识别。

## 二维码提醒

1. 打开“开启提醒”，正常播放课程直播即可。
2. 二维码出现时会收到通知和提示音，同一个码持续显示时不会反复提醒。出现过的二维码可在“最近提醒”中查看。
   提醒栏会展示实际检查的画面、来源和最近检查时间，你可以直接核对监测内容；多个画面会分别显示，并注明本次是否识别到二维码。
3. 只有无法自动读取画面时，页面才会显示“选择直播画面”。点击后直接选择正在播放的直播，无需打开额外页面。共享期间请保留扩展页面。

关闭开关即可停止提醒和共享。程序会自动调整识别速度，无需设置参数。更新扩展后，请重新加载扩展并刷新直播页面。

识别在本地完成，不上传画面、不保存录像。预览只在提醒栏可见时按需更新，不保存到通知历史；关闭提醒会清空预览。若未收到桌面通知，请检查系统是否允许 Chrome 发送通知。

## 开发与验证

扩展可直接加载，无需构建。开发测试使用 Node.js 和 npm：

```sh
npm ci
npm run check
npm test
npx playwright install chromium
npm run test:browser
```

自动化测试使用隔离的 Chromium 和模拟直播，覆盖真实 QR 像素解码、去重、设置保存、共享取消/停止与资源释放、跨域画面限制提示、通知、提示音后台文档以及原有界面，并在 4 倍 CPU 限速下验证备用 jsQR 解码。共享选择器由测试媒体流替代，不会读取实际桌面。真实交大直播、登录状态和操作系统通知展示仍需在使用环境中确认。

`npm test` 也可独立运行全部 Node 源码测试，无需浏览器。新版迁移使用公开前端脚本做静态分析，通过 Node DOM / VM 测试验证入口发现、新版 iframe、字幕节次切换和消息来源校验；此轮迁移未使用 Browser Use，也未运行浏览器自动化或登录教学平台。

### 识别实现

- 原生 `BarcodeDetector` 支持 QR 时优先使用原生实现，其他情况使用内置 jsQR 1.4.0，无需远程服务。
- 每次启动自动使用默认策略：单次扫描后等待 1.5 秒，最长边最多 960 像素；等待时间随解码耗时自动增加，最多 8 秒。多个视频轮流检查，备用解码器每次最多返回一个码。技术信息仅用于内部状态，不在用户界面显示。
- 连续显示的相同码只提醒一次；同码重现需同时满足至少 10 秒未识别到该码和 1 分钟提醒间隔。同一标签页多个 iframe 的相同码会合并提醒。
- 画面限制时提示选择直播；没有找到视频超过约 15 秒时也提供此入口。直播暂停、页面冻结、系统休眠、负载较高、小码或模糊画面都可能导致延迟或漏检。
- 最近 20 条提醒和去重信息仅保存在浏览器会话存储中，浏览器重启或扩展重新加载后清除。不会自动打开或执行二维码内容。
- 预览复用已解码的 canvas，按需缩到最长边 480 像素并使用 JPEG；查看页隐藏后不再请求，采集端的临时预览缓存会到期清除。图像只通过本地扩展消息传递，不写入 storage。预览请求独立于提醒队列，避免画面暂不可用时拖慢通知。
- `notifications` 权限用于桌面通知，`offscreen` 用于提示音。自动读取范围限于交大课程页及现有视频应用路径，其他画面需通过共享选择器指定。

## 课堂视频概要生成

1. 如需 AI 总结，点击右上角“AI 设置”，在弹窗中选择供应商和模型，填入 API Key 后点击“保存”。
2. 可在“AI 设置”中点击“测速”；导出时会默认先自动测速。
3. 可选择默认模板：默认、期末复习或 LaTeX 笔记；也可在“追加 Prompt”中写入自己的整理要求。
4. 在“课堂视频”模块中勾选要导出的日期，也可以点击“全选”。
5. 鼠标悬浮在某一天上，可预览当天字幕。
6. 点击“导出所选范围”。
7. 处理完成后，点击日志栏中的下载按钮保存 ZIP。

## 导出文件

扩展会在下载目录中生成一个 ZIP 文件，解压后通常包含：

- `导出索引.md`
- `AI整理/YYYY-MM-DD-课堂笔记.md`
- `AI整理/YYYY-MM-DD-复习资料.md`
- `AI整理/YYYY-MM-DD-LaTeX 笔记.tex`
- `原字幕/YYYY-MM-DD-原字幕.md`

如果关闭“使用 AI”，ZIP 中不会生成 `AI整理/` 文件，只会导出原字幕。

## 常见问题

- 找不到课程页面：确认 Chrome 已经登录 `https://oc.sjtu.edu.cn/`。
- 读取不到回放：重新登录课程平台后再点“重新读取”。
- 某一天导出失败：在“导出范围”中只勾选这一天，再重新导出。
- AI 总结失败：检查供应商、模型名、API Key、余额和网络；也可以关闭“使用 AI”后只导出原字幕。
